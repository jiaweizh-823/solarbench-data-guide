# SKIPPD — Stanford

Stanford（美国）站点；SolarBench 地面模态：sky_image, PV。原始数据格式、有效时段与处理后的 benchmark 不完全相同。

- 地理位置：37.427, -122.174；美国。
- 气候：Csb。
- SolarBench 选取时段：2017-03-09 至 2019-10-26（[论文补充表 1](https://arxiv.org/html/2609.06187v1)）。
- 访问状态：`public_repository`，核查日期 2026-11-11。
- 核查结论：HF 公开 API 已确认仓库存在、非私有、非 gated；全量下载未执行。
- 数据许可：[原始条款](https://huggingface.co/datasets/solarbench/SKIPPD)；CC BY 4.0（HF 仓库数据卡）。

## 原始入口

- **HF 数据集及配置**：[huggingface](https://huggingface.co/datasets/solarbench/SKIPPD)
  - 验证：`public_api_verified`。
- **HF 仓库文件元数据**：[metadata_api](https://huggingface.co/api/datasets/solarbench/SKIPPD)
  - 验证：`repository_public`。
- **作者代码与原始数据说明**：[documentation](https://github.com/yuhao-nie/Stanford-solar-forecasting-dataset)
  - 验证：`official_source`。
